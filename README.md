# Next.js – Estudos de Desenvolvimento Full-Stack

Projeto desenvolvido durante meus estudos na FIAP, no capítulo de Next.js, com foco no consumo de APIs e no desenvolvimento Full-Stack.

## 📚 Sobre o projeto

O projeto tem como objetivo colocar em prática os conceitos de Next.js, explorando funcionalidades do framework e a integração entre frontend e backend em uma única aplicação.

## 🚀 Tecnologias e conceitos estudados

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- API Routes
- Métodos HTTP (GET, POST, PUT e DELETE)
- Fetch API
- Operações CRUD
- Variáveis de ambiente
- Deploy com Vercel

## 🎯 Objetivos de aprendizagem

- Compreender a estrutura de um projeto Next.js.
- Criar e utilizar API Routes.
- Consumir APIs utilizando Fetch.
- Implementar operações CRUD.
- Trabalhar com variáveis de ambiente.
- Realizar o deploy de uma aplicação utilizando Vercel.

## 🌐 Deploy

Aplicação publicada utilizando a plataforma Vercel.
